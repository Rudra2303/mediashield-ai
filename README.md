## 📌 About the Project

MediaShield AI is a web application that helps users upload images, optimize them using Cloudinary transformations, and analyze their content using Cloudinary AI.

The project demonstrates how Cloudinary can be used as an active part of an AI-powered media workflow rather than simply storing images.

## 🎯 Problem

Managing digital media often involves several steps:

- Uploading images
- Optimizing image quality and format
- Resizing media for different devices
- Understanding image content
- Preparing media for professional use

MediaShield AI combines these steps into one simple workflow.

## ✨ Features

### 📤 Media Upload

Users can upload images directly through the application.

### ☁️ Cloudinary Media Management

Uploaded images are stored and delivered through Cloudinary.

### ⚡ Automatic Optimization

Cloudinary transformations are used to:

- Automatically select an efficient format
- Automatically optimize image quality
- Resize images

The application uses:

`f_auto`

`q_auto`

`w_800`

### 🤖 AI Media Analysis

Cloudinary AI analyzes the uploaded image and provides information about:

- Image description
- Objects visible in the image
- Professional-use suitability
